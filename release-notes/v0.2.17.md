# SuperAI Agent v0.2.17

这是 SuperAI Agent 品牌化之后的第一个正式 GitHub Release。此前 v0.2.1 ～ v0.2.16 的功能只随便携版 zip 分发，桌面端与终端 UI 一直自报 `0.2.0`；从本版起桌面端（`SuperAIAgent.exe`）与终端 UI（`superai.exe`）共用同一个版本号，桌面端「关于 → 应用更新」也改为从本仓库的 GitHub Release 检查更新。

## 主要更新（相对 v0.2.0）

- **两种产品模式**：Codex 风格的 **Work**（面向普通办公用户）与 **Code**（面向开发者，默认）；侧边栏品牌处一键切换。Work 模式内置 **Assistant / Sales / Analyst** 三个职场角色，角色目录放在 `~/.superai` 下、可直接编辑。
- **连接器目录**：MCP 设置页新增一键接入的职场连接器（飞书 / Lark、Microsoft 365 邮件与日历），并对会改变外部系统的 MCP 调用（发送、创建、删除等）强制弹出授权确认。
- **办公文档 agent**：内置 `office` agent，以 OfficeCLI 为首选引擎处理 Word / Excel / PowerPoint / PDF 及图片、视频任务；OfficeCLI 已随 Windows 便携包与 macOS 包内置，接收方无需安装任何东西。
- **OpenAI Codex 供应商**：`runtime: codex` 的会话通过本机 `codex` CLI 运行，复用 ChatGPT 登录。
- **Computer Use（Windows）**：新增只读的 `read_ui_elements` 工具快速定位界面元素；「已授权应用」列表清理了语言包、MSI 组件、驱动工具等不可控条目。
- **终端 UI 首次启动配置供应商**：`superai.exe` 首次启动直接配置 SuperAI 的模型供应商（预设 / API Key / 自定义 Base URL，真实请求验证后写入与桌面端相同的 `~/.claude/superai` 存储），不再显示 Claude Code 的登录菜单；即使本机已登录 Claude 账号也会提供一次；会话中可用 `/provider` 随时切换。
- **终端 UI 会话提示**：在已有会话的目录里再次启动时，标题区提示 `Last session …: superai -c continues it · /resume picks another`；便携包 README 与 FAQ 补充了 `-c` / `-r` / `/resume` / `/compact` 的说明。
- **对话新开目录**：聊天输入框新增文件夹选择按钮，可在新标签页中以任意目录开始会话。

## 问题修复

- 修复终端 UI 在传统 Windows 控制台（CJK 字体）下的重影分隔线与徽标显示问题。
- 修复终端 UI 在已登录 Claude 账号的机器上误显示「Auth conflict … /logout」提示的问题。
- 修复便携包打包脚本在目标目录被占用时会把目录清空一半的问题：现在会拒绝并给出占用进程，或改用 `-OutDir` 打到别处。
- 修复桌面端更新检查指向错误仓库（无任何 Release）导致 "Could not fetch a valid release JSON" 的问题；错误提示现在会说明是「尚未发布 Release / 仓库不公开 / 网络不可达」而不是笼统失败。

## 其他说明

- 便携版 zip 仍随每次发布提供；GitHub Release 中的安装包（Windows NSIS / macOS DMG / Linux deb）用于桌面端的在线更新。
- 版本号来源统一为 `desktop/src-tauri/tauri.conf.json`，`bun run scripts/release.ts <patch|minor|major|x.y.z>` 会同步更新桌面端与终端 UI（`preload.ts`）并打 tag。
