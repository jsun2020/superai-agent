# SuperAI Agent v0.2.21

为「流式连接中断后服务商返回空响应」错误增加现场诊断信息。

## 改进

- **空响应错误现在自带诊断尾部**：v0.2.20 把企业代理切断长流式响应后的静默失败改成了明确错误，但错误文本是固定的，无法判断降级请求到底收到了什么。从本机对真实 MiniMax API 的全部探测（170k 字符系统提示词、每分钟约 25 万 token 的连发、流式切断后立即重发同一请求、畸形请求形态）均正常——空响应只存在于出问题机器的网络路径上。现在错误信息会附加一段有界的诊断尾部 `[diagnostic: stream_error=...; response_keys=...; stop_reason=...; usage=in:N,out:N; extra base_resp=...]`，包含流式失败原因、降级响应的顶层字段、stop_reason、token 用量，以及所有非 Anthropic 标准字段（例如 MiniMax 以 HTTP 200 + `base_resp` 上报的软错误，或代理伪造的 JSON 响应体）。一张报错截图即可定位根因，无需 --debug 日志。
