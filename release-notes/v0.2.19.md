# SuperAI Agent v0.2.19

新增终端 UI 的 bypass permissions 模式循环，并修复 MiniMax 等 Anthropic 兼容服务商的对话报错。

## 新功能

- **终端 UI 权限模式循环加入 `bypass permissions on`**：Shift+Tab（部分终端为 Alt+M）现在按 `default → accept edits on → plan mode on → bypass permissions on → default` 循环。首次进入 bypass 会弹出一次性警告对话框：接受后写入 `skipDangerousModePermissionPrompt`（每台机器只问一次）；拒绝则回到之前的模式，并在本次会话中不再提供 bypass。可通过环境变量 `SUPERAI_BYPASS_IN_CYCLE=0` 或设置 `permissions.disableBypassPermissionsMode: "disable"` 关闭；Unix 上 root（非沙箱）不提供该模式。

## 问题修复

- **MiniMax 等 Anthropic 兼容服务商对话报错 `undefined is not an object (evaluating 'K.input_tokens')`**：服务商「测试」连通，但 GUI 和终端 UI 每轮对话都失败。原因是这类服务商对流式请求可能返回非 SSE 响应，客户端会自动降级为非流式请求；而其响应缺少 `usage` 字段，成本统计代码在 `finally` 中对 undefined 取 `usage.input_tokens` 抛错，导致已收到的回复被错误覆盖。现在缺失的 `usage` 会被归一化为零值（无 token 上报即计费为 $0），对话正常返回。
