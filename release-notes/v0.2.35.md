# SuperAI Agent v0.2.35

新增「SuperAI Agent in Chrome」：一个 Chrome 扩展（Manifest V3），把智能体放进浏览器侧边栏，并让页面的调试状态随每条消息自动送达。

## 新功能

- **侧边栏对话**：点击扩展图标打开侧边栏，直接询问当前页面的问题。侧边栏是桌面应用本地服务（`127.0.0.1:3456`）的瘦客户端——会话、流式输出、工具、权限确认和服务商（Claude / Codex / 企业网关）全部沿用桌面端，浏览器里不运行任何第二套引擎。
- **页面调试上下文自动附带**（可关闭）：最近的控制台错误/警告与未捕获异常（含文件:行:列）、失败的网络请求（HTTP 4xx/5xx 与网络层错误，含方法、URL、资源类型）、以及页面 URL/标题/视口，作为 `<page-debug-context>` 块置于消息之前。每条、每节与整体均有长度上限：一个疯狂报错的页面也只会产生有界的上下文，且会说明省略了多少。
- **右键「Ask SuperAI Agent about this element」**：把所点元素的 CSS 路径与裁剪后的 HTML 附到下一条消息，同时打开侧边栏。
- **截图**：一键把可见标签页截图作为图片附件发送。
- **项目文件夹**：在设置里填入站点源码目录，智能体即可读取与修改代码；修改前会在侧边栏请求确认（Allow / Deny）。
- 缓冲区按标签页隔离、有界（200 条控制台、100 条网络），页面导航时清空；扩展被空闲回收后仍能从会话存储恢复。

## 实现说明

- `chrome-extension/`：`page-hook.js` 运行在页面主世界拦截 console 与错误事件；`content.js`（隔离世界）转发并记录右键元素；`background.js` 持有每个标签页的缓冲、监听 `webRequest`、处理右键菜单与截图；侧边栏为 React 页面。
- 上下文格式化与对话流式归约都是纯函数，各自有测试；React 只负责渲染。
- 服务端唯一改动：CORS 允许 `chrome-extension://<id>` 来源（含测试）。协议未变。

## 安装（开发者模式）

`cd chrome-extension && bun install && bun run build`，然后在 `chrome://extensions` 开启开发者模式，「加载已解压的扩展程序」选择 `chrome-extension/dist`。需要 Chrome 116+，并先启动桌面应用。

## 隐私

捕获的内容不离开浏览器；只有在按下发送时，才作为你自己的消息发往设置中的本地服务地址。每条消息的摘要会显示随其发送的上下文数量。

## 尚未包含（v0.2.36 规划）

智能体还不能在对话中途主动操作页面（导航、点击、重新拉取日志）。计划通过 MCP 向会话暴露浏览器工具并由本扩展执行。

## 验证

- 纯模块 15 项测试（上下文格式化的上限与省略提示、成功请求不上报、元素附带、归约器的流式/工具/权限/错误路径）；服务端 CORS 测试 4 项。
- 以侧边栏的方式探测真实服务：扩展来源的预检 204 并回显来源、创建会话 201、WebSocket 首个事件 `connected`、ping→pong。
- 扩展 `tsc` 通过；构建产物 7 个文件；两个经典脚本经检查不含 import/export 语句。
- 浏览器内端到端（加载扩展、真实页面报错随消息发送、权限往返）需在 Chrome 中手动验证。
