# SuperAI Agent v0.2.18

修复企业网络下的 TLS 证书问题。

## 问题修复

- **企业代理（TLS 解密）下无法连接 API**：在用公司 CA 重新签发证书的企业代理后面，桌面端、终端 UI 和服务商「测试」全部报 `Unable to connect to API: Self-signed certificate detected` / `self signed certificate in certificate chain`，而「网络代理 → 测试」显示 200（它只做 CONNECT 握手、不校验证书）。原因是 Bun 运行时只信任自带的 Mozilla 根证书，不读系统证书库。现在 Windows / macOS 上默认**同时信任系统证书库**：
  - 终端 UI / 会话内 API 调用：把系统证书库的 CA 追加到信任列表（`SUPERAI_USE_SYSTEM_CA=0` 可关闭；`NODE_EXTRA_CA_CERTS`、`--use-system-ca` 含义不变）。
  - 桌面端：启动时把系统证书库导出到 `~/.claude/superai/system-ca.pem`，以 `NODE_EXTRA_CA_CERTS` 传给 API 服务与 IM 适配器两个 sidecar（Bun 只在进程启动时读取它）；用户自己设置的 `NODE_EXTRA_CA_CERTS` 优先。
  - 服务商「测试」与 OpenAI 格式转换代理使用与会话相同的 TLS 信任设置。
