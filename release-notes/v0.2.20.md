# SuperAI Agent v0.2.20

修复企业代理下 MiniMax 等服务商长思考对话的静默失败。

## 问题修复

- **企业代理切断长流式响应后，对话以晦涩错误或静默停止收场**：在 TLS 解密型企业代理后面，MiniMax-M3 等模型思考较久（30 秒以上）时，代理可能中途切断 SSE 流。客户端会自动降级为非流式请求；当降级响应不含任何内容块时，GUI 显示 `[ede_diagnostic] result_type=assistant last_content_type=none stop_reason=null`，终端 UI 则静默结束本轮、任务没有完成。现在这种空响应会显示明确可重试的错误提示（"The provider returned an empty response after the streaming connection was interrupted..."）；降级响应正常时仍然无感恢复。已用模拟服务商对切断/空响应/正常三种形态逐一验证；对真实 MiniMax API 的探测（流式/非流式、思考开/关、工具往返、170k 字符 CLAUDE.md）均协议合规，问题触发点是网络路径而非服务商协议。
